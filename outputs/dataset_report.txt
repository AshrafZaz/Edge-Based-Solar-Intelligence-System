6. TIME-SERIES FORECASTING SUITABILITY ASSESSMENT
------------------------------------------------------------
Suitability Analysis:
1. Sampling Frequency: Average sample delta is ~50-60 minutes (approximately 9-10 daylight readings per day).
   - This implies next-step forecasting corresponds to ~1 hour ahead (the next daylight measurement),
     or predicting future power based on prior lags within daylight hours.
2. Diurnal Solar Curve: The data captures solar irradiance rising from morning (~8:00 AM), peaking near solar noon (~12:00-14:00 PM), and declining in afternoon (~16:00 PM).
3. Hardware Sensor Alignment & Mismatch Analysis:
   - Dataset contains: SolarIrradiance (W/m²), Temperature (°C), Humidity (%), Voltage (V), Current (A), Power (W).
   - ESP32 Hardware measures: Temperature (°C via DHT22), Humidity (% via DHT22), LDR Status (digital HIGH/LOW), Voltage (V via INA219), Current (mA via INA219), Power (mW via INA219).
   - Crucial Mismatch & Scientific Alignment:
     * ESP32 measures current in mA and power in mW; dataset records current in A and power in W (1 A = 1000 mA, 1 W = 1000 mW). Unit scaling must be strictly standardized.
     * Dataset has continuous pyranometer irradiance (W/m²); ESP32 has a digital LM393 LDR module (HIGH/LOW).
       Per project instructions: 'Do not treat LDR HIGH/LOW as a real irradiance measurement.'
       Therefore, the ML forecasting model must rely on scientifically valid features obtainable across both domains:
       Temperature, Humidity, Operating Voltage, Operating Current, Historical Power Lags, and Time-of-day harmonic features.
     * Furthermore, contemporaneous P = V * I target leakage must be avoided: contemporaneous Voltage and Current cannot be used to predict contemporaneous Power!
       Instead, lag features (Power_{t-1}, Temperature_{t}, Humidity_{t}, Voltage_{t-1}, Current_{t-1}, TimeOfDay) must be used to forecast Power_{t}.
